# 던전 카드 모험 — 소수의 나눗셈 편 (6학년 2학기)

쌓기나무 버전과 같은 게임이고, **문제만 소수의 나눗셈으로 바뀐 버전**이에요.
문제를 풀 때마다 카드 3장 중 1장을 골라 18장 덱을 만들고, 친구와 1:1로 대결해요.
대결 규칙, 카드, 매칭, 교사 화면, 그림은 쌓기나무 버전과 완전히 같아요.

---

## 올리는 방법 (Render)

1. zip을 풀고, **폴더 안의 내용물**(`server.js`, `package.json`, `game`, `public` 등)을 GitHub 저장소 맨 위에 올려요. 폴더째 올리면 Render가 `package.json`을 못 찾아요. `node_modules`는 올리지 마세요.
2. Render에서 Web Service를 만들고 저장소를 연결해요. Build Command는 `npm install`, Start Command는 `npm start`예요.
3. Environment에 `ADMIN_PASSWORD`를 꼭 넣어 주세요. (안 넣으면 기본값 `teacher1234`)
4. 학생용 주소는 `https://…onrender.com`, 교사용 주소는 `https://…onrender.com/teacher.html`이에요.

쌓기나무 버전과 **저장소를 따로 만들어서** 올리는 것을 추천해요. 같은 저장소에 덮어쓰면 쌓기나무 버전이 사라져요.

---

## 수업 진행

1. 수업 1~2분 전에 교사 화면에 들어가 서버를 깨워 두세요.
2. 교사 화면에서 로그인하고 **반 만들기** (예: `6-1`, 24명)
3. 학생: 반 → 번호 → **모험 시작** → 문제 풀기 → 카드 3장 중 1장 고르기를 12번 반복
   - 틀리면 같은 문제를 다시 풀어요. 5번 연속으로 틀리면 남은 칸이 가뭄 카드로 채워져요.
4. 18장이 모이면 **대결 찾기** → 접속한 학생이 모두 대기열에 들어오면 무작위 대결 (홀수면 한 명은 연습 로봇)
   - 오래 기다리게 되면 교사 화면의 **지금 대기 중인 학생끼리 매칭** 버튼을 누르세요.
5. 대결이 끝나면 카드 5장을 계승하고, 7문제를 더 풀어 다시 18장을 채워요.

---

## 문제 유형 (7가지)

학생마다 7가지 유형이 한 묶음으로 섞여서 차례로 나와요. 그래서 12문제 안에 모든 유형이 골고루 나와요.

| 유형 | 예 | 풀이 방식 |
|---|---|---|
| 소수 ÷ 소수 | 21.36 ÷ 0.89 | 숫자 입력 (세로셈 그림) |
| 자연수 ÷ 소수 | 21 ÷ 0.3 | 숫자 입력 (세로셈 그림) |
| 소수점 옮겨 계산 | 36.9 ÷ 4.5 = 3690 ÷ □ | 숫자 입력 (×10, ×100 화살표 그림) |
| 문장 문제 | 페인트 20.7 L로 몇 m²? | 숫자 입력 (막대 그림, 단위 표시) |
| 몫의 소수점 위치 | 252 ÷ 12 = 21 을 이용해 25.2 ÷ 1.2 | 4지선다 |
| □ 구하기 | □ ÷ 1.8 = 22 | 숫자 입력 |
| 몫의 크기 비교 | 몫이 가장 큰 식 고르기 | 4지선다 |

**출제 범위**
- 몫이 **소수 첫째 자리 이내로 딱 떨어지는 문제만** 나와요. 반올림이나 나머지를 구하는 문제는 없어요.
- 나누어지는 수는 소수 둘째 자리까지, 나누는 수는 소수 둘째 자리까지(0.49 이하)예요.
- 문장 문제는 단위(컵, 도막, 봉지, 시간, 분, m² 등)를 화면에 보여 줘서 숫자만 입력하면 돼요.
- 정답 입력은 `4.2`와 `4.20`을 같은 답으로 봐요. 쉼표(`4,2`)도 받아 줘요.
- 계산은 정수로 해서 소수 계산 오차가 생기지 않아요.

## 알아 두실 점

- 기록은 서버 메모리에만 저장돼요. 서버가 재시작되면 반을 다시 만들어야 해요.
- 문제 수는 제한이 없고 매번 새로 만들어져요. 정답은 학생 화면으로 가지 않아요.
- 카드 수치와 설정(HP, MP, 턴 시간)은 `game/cards.js`에서 바꿀 수 있어요.
- 문제 범위를 바꾸고 싶으면(예: 몫이 자연수인 문제만) `game/problems.js`를 수정해야 하니 Claude에게 부탁하세요.
- 쌓기나무 버전의 그림 바꾸기, 카드 id 목록 안내는 이 버전에도 그대로 적용돼요.
